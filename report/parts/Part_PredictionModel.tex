\chapter{候选模型与基准选择}

\section{预测问题描述}

本研究把热度回归限定为一个发布前预测问题：只使用内容发布时即可获得的结构化字段，预测点赞、收藏和评论加权得到的连续互动量。该限定排除了发布后早期互动、平台曝光量等会造成目标泄漏或在当前数据中不可得的变量。连续输出可用于候选内容的相对排序，但不能被解释为对单篇笔记最终互动量的确定性承诺。

实际比较包括中位数常数基线，以及普通线性回归、Ridge回归、随机森林、极端随机树和直方图梯度提升五个学习模型。它们覆盖了可解释的线性关系、带正则化的线性关系和非线性树集成，同时能够在统一的60,000条分层样本上完成可复现比较。SVR、XGBoost、LightGBM、LSTM、Transformer和多模态模型在本轮没有产生数值实验；下文仅将这些方法作为候选方法或后续扩展讨论，不把其理论优势写成当前数据上的实证结论。

\section{线性回归模型}

线性回归模型是回归分析中最基础、最经典的模型。它假设因变量（如帖子点赞数或观看量）与一个或多个自变量（如字数、图片数、tag数）之间存在线性关系。该模型的优点是形式简单、易于实现和解释，计算效率高，能够快速提供特征与热度之间的边际效应分析。在社交媒体分析领域，线性回归常被用作初步探索变量之间关系的工具，或作为更复杂模型的基准。例如，可以用来量化"每增加一张图片平均能带来多少额外点赞"或"晚间发布相比午间发布的热度差异"。

然而，其最大的局限性在于线性假设，这使其难以捕捉社交媒体数据中普遍存在的非线性关系（如tag数量与热度之间可能存在的倒U型关系）。此外，线性回归对异常值（如偶然爆红的 viral content）和多重共线性（如粉丝数与历史平均点赞数高度相关）较为敏感，这可能会影响其预测的准确性和稳健性。尽管如此，由于其简单性和可解释性，线性回归模型仍然是一个重要的基准，可以用来评估更复杂模型在处理非线性问题上的增益，并为特征重要性提供直观的理解。

\subsection{经典线性模型}
普通最小二乘法（OLS）线性回归作为最基础的学习型基准，用于检验10项结构化特征能否提供近似线性的预测信号。

\subsection{正则化线性模型}
本轮同时纳入L2正则化的Ridge回归，用于检查收缩系数后是否能够改善泛化；L1正则化的Lasso未纳入最终数值比较。

\section{候选方法：支持向量回归（SVR）}

支持向量回归（Support Vector Regression, SVR）是支持向量机（SVM）在回归问题上的重要应用，它继承了SVM在处理小样本、非线性及高维模式识别问题中的诸多优势。SVR的核心思想是寻找一个最优的回归函数（或称为超平面），使得所有训练样本点与该函数之间的偏差最小，同时保证模型的泛化能力。其最大的创新在于引入了"$\epsilon$-不敏感损失函数"（$\epsilon$-insensitive loss function）。该函数设定了一个宽度为$2\epsilon$的"容忍带"，只有当预测值与真实值之间的误差超出这个容忍带时，才会计算损失并进行惩罚。这种机制使得模型对容忍带内的小误差不敏感，从而提高了对噪声数据的鲁棒性，并使得模型解具有稀疏性，即只有少数"支持向量"对最终的回归函数有贡献。

在小红书热度预测中，SVR理论上可用于拟合结构化特征与热度之间的非线性关系。不过，核方法在大样本上的训练成本较高，本轮统一实验没有运行SVR，因此不能据此判断它在当前数据上是否优于线性或树模型。

SVR模型有三个关键参数需要调优：
\begin{itemize}
	\item 容忍带宽度 ($\epsilon$)：$\epsilon$决定了对误差的容忍程度。$\epsilon$越小，模型对拟合精度的要求越高，可能导致模型复杂、过拟合；$\epsilon$越大，模型越简单，但可能欠拟合。在小红书数据中，由于热度分布通常呈现长尾特性，需要谨慎设置以避免对高热度异常值过度敏感。
	\item 惩罚系数 (C)：C控制了对超出容忍带的样本的惩罚力度。C越大，对误差的惩罚越重，模型倾向于将所有样本都拟合好，可能过拟合；C越小，允许更多的误差，模型泛化能力可能更强。考虑到小红书帖子热度的极端方差，C的选择需要平衡对 viral content 的拟合能力。
	\item 核函数 (Kernel Function)：核函数是SVR处理非线性问题的关键。通过核技巧，SVR可以将原始数据映射到更高维的特征空间，从而在新的空间中寻找线性回归函数。常用的核函数包括线性核、多项式核和高斯径向基函数（RBF）核。RBF核因其良好的性能和普适性，在处理文本、图像混合特征的社交媒体数据中被广泛使用。
\end{itemize}

如在后续研究中加入SVR，应在与现有模型完全相同的数据切分和特征口径下调参，并同时报告运行成本与测试集指标。

\section{本轮采用的树集成模型}

集成学习通过组合多个基学习器降低单棵树的方差，或逐步修正残差以拟合非线性关系。随机森林是典型的Bagging方法\cite{Breiman2001}，梯度提升则按迭代方式拟合前一轮残差。考虑到当前输入仅有10项表格型特征，本轮选择随机森林、极端随机树和直方图梯度提升树，避免把不同第三方框架的工程差异混入主要比较。

随机森林通过自助采样和随机特征子集训练多棵树；极端随机树进一步随机化候选切分点。两者都能表达非线性和交互，但特征重要性只表示预测贡献，不能直接解释为因果效应。直方图梯度提升先将连续特征分箱，再逐轮拟合残差，适合在较大表格数据集上控制训练成本。XGBoost等框架具有成熟的正则化与高效实现\cite{ChenGuestrin2016}，但本轮未使用，因而不参与结果排名。

\section{后续候选：深度学习与多模态模型}

循环神经网络、卷积神经网络和预训练语言模型能够从序列、图像或文本中学习表示，但采用这些模型的前提是获得与每条笔记稳定对应的原始模态数据。当前数据只有结构化字段和文本摘要，缺少严格对齐的图片张量与发布后时间序列，因此以下内容属于方法储备，不属于本轮实证。

长短期记忆网络（Long Short-Term Memory, LSTM）是一种特殊的RNN，专门设计用于解决传统RNN在处理长序列时面临的梯度消失和梯度爆炸问题。LSTM通过引入一个精巧的门控机制（包括输入门、遗忘门和输出门）来控制信息流，使其能够有选择地记忆和遗忘信息，从而有效地捕捉时间序列中的长期依赖关系。在小红书热度预测中，LSTM可以用于建模用户互动的时间动态，例如，基于发布后1小时、2小时、6小时的点赞/收藏序列，预测24小时后的最终热度。这种早期热度序列往往包含了内容质量的重要信号。

卷积神经网络（Convolutional Neural Network, CNN）在图像识别领域取得了巨大成功，其强大的局部特征提取能力也被成功应用于文本分析（TextCNN）。在小红书场景下，TextCNN可以通过不同大小的卷积核捕捉标题和正文中的局部语义特征（如关键词组合、情感表达模式），有效识别"爆款标题"的文本模式。对于图像数据，可以使用预训练的CNN（如ResNet, VGG）提取视觉特征，评估图片质量、美学得分和内容相关性。

预训练语言模型（BERT, RoBERTa）通过大规模语料预训练，能够深度理解小红书文本内容的语义和上下文信息。利用BERT对标题和正文进行编码，可以获得高质量的文本表征，捕捉隐含的情感倾向、话题类别和写作风格，这些都是影响热度的重要因素。

此外，可以构建多模态融合模型（Multi-modal Fusion），将文本特征（BERT）、视觉特征（CNN）和结构化特征（元数据）在特征层或决策层进行融合，全面捕捉影响热度的多维度因素。

\subsection{时序深度学习模型：LSTM/GRU}
若未来能够获得发布后前$N$小时的连续互动快照，可比较LSTM/GRU与简单增长曲线基线；这将属于“发布后早期预测”，必须与本文的“发布前预测”任务分开报告。

\subsection{文本深度学习模型：BERT + TextCNN}
完整标题和正文可用于比较BERT编码、TextCNN和词袋基线。只有在固定数据切分上证明其测试集增益后，才能认为深层语义特征为结构化基准提供了额外信息。

\section{其他未验证候选方法}

\subsection{宽度学习系统（Broad Learning System, BLS）}
宽度学习是一种新兴的平坦神经网络架构，通过随机生成特征节点和增强节点，利用伪逆快速计算输出权重，具有训练速度极快、结构灵活的特点。在小红书实时热度预测场景中，BLS可以作为快速基准模型，支持模型的在线更新和增量学习。

\subsection{生存分析模型（Survival Analysis）}
考虑到部分小红书帖子可能长期持续获得流量（"长尾内容"），而另一些则快速衰减，可以引入生存分析中的Cox比例风险模型或AFT（Accelerated Failure Time）模型，不仅预测总热度，还预测热度的持续时间和衰减速度，为评估内容的长期价值提供依据。

本章记录多模态融合、用户行为动态建模和上下文感知等扩展方向。它们尚未在当前数据上实现，不能与下一章的结构化基准共享“已完成”状态。每一种扩展都需要先补齐输入数据，再在相同切分上与现有基准比较。

\section{模型架构设计}

模型扩展应首先服务于可检验的问题：新增模态是否在严格测试集上提供独立增益，增益是否能够跨时间与跨博主保持。只有回答这些问题后，预测分数才适合进入受控的决策支持流程。

可检验的候选方向包括：

\begin{itemize}
	\item 多模态深度融合：现有的多模态方法通常采用简单的特征拼接或浅层融合。我们将探索更先进的融合机制，如基于注意力机制的多模态融合（Attention-based Fusion）、跨模态Transformer（Cross-modal Transformer），让模型自动学习文本、图像、时间、空间特征之间的复杂交互关系。例如，模型可以学习到"美食类内容在晚间配合高饱和度图片效果更佳"这样的隐性规则。
	
	\item 图神经网络（GNN）应用：构建用户-内容-标签的异构图网络，利用图神经网络捕捉社交关系、内容相似性和标签共现关系。通过消息传递机制，模型可以借鉴相似内容的历史表现，或利用用户的社交影响力来修正热度预测，解决冷启动问题。
	
	\item 多任务学习框架：不同于单一预测观看量或点赞数，我们将构建多任务学习模型，同时预测多个热度指标（观看量、点赞数、收藏数、评论数、分享数）。通过共享表征层，模型可以学习到不同互动行为之间的内在关联（如"高收藏内容通常评论较少但转化率较高"），提高整体预测精度。
	
	\item 时序卷积网络（TCN）与Transformer：引入Temporal Convolutional Network和Transformer架构替代LSTM，利用其并行计算优势和长距离依赖捕捉能力，更有效地建模热度传播的时间动态，特别是捕捉突发流量和病毒式传播模式。
	
	\item 因果推断集成：结合因果推断方法（如双重机器学习、倾向得分匹配），不仅预测相关性，还尝试识别因果关系，区分"因为发布了某类内容所以热门"和"因为账号本身有影响力所以热门"，为内容策略提供更 robust 的建议。
\end{itemize}

策略融合方面，我们将探索如何将回归预测模型的输出直接转化为内容优化策略。例如：

\begin{itemize}
	\item 实时发布决策支持：构建一个策略系统，当模型预测某篇草稿在特定时间、搭配特定标签发布能获得更高热度时，向创作者推荐最佳发布时机和标签组合。
	
	\item A/B测试优化：模型可以帮助筛选待测试的标题或封面版本，但离线预测不能替代随机A/B测试；真实增量效果仍须通过受控实验估计。
	
	\item 动态流量分配：对于品牌方和MCN机构，预测模型可以用于评估不同KOL的内容投放效果，优化广告预算分配，识别潜在的高性价比投放对象。
	
	\item 内容冷启动策略：针对新账号或新内容，利用预测模型识别"潜力内容"，建议平台给予初始流量扶持，提高优质内容的发现效率。
\end{itemize}

上述方案只有在数据完整性、时间外泛化和增量实验均通过验证后，才可视为对当前结构化基准的有效扩展。下一章先报告已经完成且可以复现的回归实验。

\chapter{热度回归模型实证}

\section{任务定义与数据处理}

为将前述方案落实为可复现实验，本章将笔记热度定义为连续互动量
\begin{equation}
	y=\text{点赞数}+\text{收藏数}+4\times\text{评论数}.
\end{equation}
评论被赋予较高权重，是因为其参与成本和互动深度通常高于点赞与收藏。该定义与分类模型部分保持一致，但不再把第80百分位以上样本离散化为高热度类别，而是直接预测连续数值。

实验读取三个业务数据压缩包中的笔记详情表，共得到323,598条原始记录。按笔记链接去重；无有效链接时，按编号、标题和博主组合去重，并剔除互动指标缺失或为负的记录，最终保留199,473条有效笔记。热度中位数为346，均值为3,298.21，第80百分位为2,134，第95百分位为12,755，最大值达到1,711,417。均值约为中位数的9.5倍，最大值又远高于第95百分位，表明目标分布具有显著右偏和长尾特征。

输入沿用分类模型部分的10项发布前特征：粉丝量对数、标题长度、正文长度、标签数、感叹号数、问号数、Emoji数、情感得分、星期和是否标注发布地。点赞、收藏和评论没有作为输入，从而避免目标泄漏。为控制不同模型的计算成本，本文按对数热度的十分位分层抽取60,000条样本，再以8:2划分训练集和测试集，得到48,000条训练样本和12,000条测试样本。缺失值填补及标准化参数均只在训练集拟合。

\section{模型与评估指标}

由于直接拟合原始热度会使少数极端爆款支配平方损失，本章令所有有效模型学习$\log(1+y)$，预测后使用$\exp(\hat y)-1$还原并将负预测截断为0。比较模型包括中位数基线、普通线性回归、Ridge回归、随机森林、极端随机树（Extra Trees）和直方图梯度提升树。

评估同时覆盖绝对误差、相对误差和排序能力。MAE与RMSE在原始互动量尺度计算；RMSLE衡量对数量级的预测误差，降低极端值的支配；$R^2$衡量模型对原始热度方差的解释比例；Spearman相关系数衡量预测排序与真实排序的一致性。运营筛选能力使用Top 20\%召回率衡量，即预测热度排名前20\%的笔记覆盖了多少真实热度排名前20\%的笔记。鉴于长尾分布，本研究以RMSLE作为主要误差指标，以Spearman和Top 20\%召回率作为重要辅助指标，而不依据单一RMSE选型。

\section{可解释性、局限与应用建议}

基于最佳梯度提升树的测试集排列重要性显示，粉丝量对数最重要，打乱该特征会使对数误差增加2.620；星期、正文长度、情感得分和是否标注发布地的重要性均值分别为0.154、0.136、0.136和0.105。标签数、标题长度、Emoji数和感叹号数提供较弱的补充信息，问号数的重要性接近0。该结果说明发布者已有影响力仍是热度预测的首要信号，但内容表达、发布时间和位置元数据共同提供了可利用的增量信息。排列重要性反映预测贡献而非因果效应，不能据此断言增加正文长度或选择某一星期发布必然提高热度。

需要审慎解释接近0的原始尺度$R^2$。虽然最佳模型显著改善了RMSLE与排序能力，但仍无法解释极端爆款造成的大部分原始方差。平台临时流量分配、突发热点、站外传播和早期互动速度没有包含在现有发布前特征中，而这些因素可能决定最极端的传播结果。因此，本模型适合用于发布前的相对热度排序、候选内容筛选和资源粗分配，不适合把单条笔记的点预测视为确定性承诺。

补充稳健性实验使用全部有效日期样本进行一次时间外切分，并按博主进行完全隔离的分组切分。梯度提升树在两种切分下的RMSLE分别为1.744和1.827，Spearman相关系数均约为0.532，且与随机切分基准相当；原始尺度$R^2$仍接近0。该结果增强了相对排序结论的可信度，但没有改变绝对量预测能力有限的判断。后续仍应采用多个滚动时间窗口复核稳定性；在获得稳定配对的原始图片、完整文本语义表示和发布者历史序列后，再比较BERT、视觉编码器及多模态融合模型。综合本轮结果，推荐使用梯度提升树进行发布前排序，并在验证集按候选名额选择Top-$K$；对极端爆款的绝对量预测则应输出区间或分位数，而不是单一点估计。
