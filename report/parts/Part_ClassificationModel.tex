\chapter{基准分类模型}

\section{预测问题描述}
在小红书内容传播效果研究中，一个核心任务是根据发布前可获得的特征判断笔记是否具有较高互动潜力。本文将全体有效样本互动量第80百分位作为阈值，把任务定义为“高热度”与“普通热度”的二分类。离散化会损失连续热度信息，却能降低少数极端互动量对平方误差的影响，并直接支持候选内容筛选。模型输出反映预测关联，不等同于加大推广后会产生的因果增量。

\section{逻辑回归}
逻辑回归（Logistic Regression）是二分类问题中常用的线性模型。它假设特征与正类对数几率之间存在线性关系，限制了其捕捉复杂非线性模式的能力，但形式简单、训练高效，适合作为性能基准。标准化后的系数方向可用于描述条件预测关联，但不能直接解释为某一特征变化造成热度变化的因果效应。
\begin{itemize}
	\item \textbf{模型原理：} 通过Sigmoid函数将特征的线性组合映射到(0,1)区间，输出样本属于正类（高热度）的概率。决策边界为线性超平面。
	\item \textbf{优势：} 计算速度快，模型参数（系数）直接可解释，能直观看出各特征对结果的正/负向影响及相对强度。
	\item \textbf{局限：} 无法自动捕捉特征间复杂的交互作用和非线性关系，对数据线性可分性要求较高。
\end{itemize}

\section{线性支持向量机}
支持向量机（Support Vector Machine, SVM）通过寻找具有较大分类间隔的超平面实现分类。本轮使用线性SVM，以便在相同10项结构化特征上与逻辑回归比较；没有采用RBF核，也没有输入文本向量、图片或多标签高维表示。
\begin{itemize}
	\item \textbf{损失函数：} 线性SVM使用间隔损失惩罚落入间隔内或被错分的样本，并由正则化参数控制间隔宽度与训练误差之间的权衡。
	\item \textbf{本轮设置：} 数值特征经训练集标准化后输入模型，并使用类别权重缓解约1:4的类别不平衡。
	\item \textbf{解释边界：} 线性决策面不能自动表达复杂交互，其分数主要用于排序；若需要概率，必须另行进行概率校准。
\end{itemize}

\section{集成学习模型}
集成学习通过组合多个基学习器表达非线性和特征交互。本轮比较随机森林与直方图梯度提升分类器；是否优于线性模型由统一测试集指标判断，而不预先假定。

\subsection{随机森林}
随机森林（Random Forest）通过自助采样（Bootstrap）构建多棵决策树，并综合所有树的投票结果进行分类。其引入的随机特征选择有效降低了模型的方差，防止过拟合。
\begin{itemize}
	\item \textbf{优势：} 能表达非线性关系，通常不需要标准化，并可提供基于树分裂的特征重要性。
	\item \textbf{本轮应用：} 模型输入仍是粉丝量对数、文本长度、符号计数、情感、星期和位置标记等10项特征，不包含封面图或完整文本语义。
\end{itemize}

\subsection{梯度提升决策树}
梯度提升决策树（Gradient Boosting Decision Trees, GBDT）以串行方式迭代训练弱学习器，每一轮根据当前模型的误差继续改进。本轮采用scikit-learn的直方图梯度提升分类器，没有运行XGBoost或LightGBM。
\begin{itemize}
	\item \textbf{优势：} 直方图分箱可以降低连续特征分裂搜索的计算成本，模型能够自动表达一定程度的非线性与交互。
	\item \textbf{本轮应用：} 该模型在统一测试集上取得最高PR-AUC和ROC-AUC；这一结果只支持当前特征与数据范围内的排序比较，不量化改变某个标签带来的因果提升。
\end{itemize}

\section{神经网络基准与后续候选}
本轮只在10项结构化特征上运行多层感知机。CNN和RNN/LSTM需要稳定对齐的图片、完整文本序列或时间序列，本节保留其方法说明，但不把它们列入数值结果。

\subsection{多层感知机}
多层感知机（Multilayer Perceptron, MLP）是最基本的深度学习模型，由全连接层和非线性激活函数堆叠而成。它可以作为深度学习方法的入门基准，用于验证经过特征工程的结构化数据是否包含足够预测信息。
\begin{itemize}
	\item \textbf{优势：} 能够学习特征间的复杂非线性组合，相比逻辑回归具有更强的表示能力。
	\item \textbf{应用：} 可将经过预处理和特征工程的所有数值和类别特征（经过编码后）输入MLP，作为与其他更复杂深度学习模型对比的基线。
\end{itemize}

\subsection{卷积神经网络}
卷积神经网络（Convolutional Neural Network, CNN）在图像处理领域取得巨大成功，但其局部感知和参数共享的思想也可应用于一维序列数据。
\begin{itemize}
	\item \textbf{应用：} 对于文本数据，可将词嵌入序列视为一维“图像”，使用一维CNN来提取短语级别的局部语义特征。对于图像特征，可以直接使用预训练的CNN（如ResNet）提取的深度特征向量作为输入的一部分。CNN能有效捕捉如“标题中的特定关键词组合”或“封面图中同时出现人脸和产品”等局部模式对热度的信号。
\end{itemize}

\subsection{循环神经网络}
循环神经网络（Recurrent Neural Network, RNN）及其变体长短期记忆网络（LSTM）专门为序列数据设计，能捕捉时间或顺序上的依赖关系。
\begin{itemize}
	\item \textbf{应用：} 在小红书笔记分类中，LSTM可用于建模文本的序列信息（如正文的语义流），或建模用户历史行为序列（如发布者过去笔记的互动趋势）以捕捉其内容质量的时序演变。然而，对于单篇笔记的静态特征分类，LSTM的优势可能不如CNN或MLP明显，除非考虑时间上下文（如当前热点话题）。
\end{itemize}

\section{实证设置与基准结果}
为将上述模型由方案说明落实为可复现实验，本文读取工作区三个业务数据压缩包中的笔记详情表，合并后共得到323,598条原始记录。按笔记链接（无链接时按编号、标题和博主）去重并剔除互动指标缺失或为负的记录后，保留199,473条有效笔记。互动量定义为“点赞数+收藏数+$4\times$评论数”，达到全样本第80百分位（2,134）的笔记记为高热度，正类比例为20.01\%。建模输入仅使用发布前或内容本身可获得的10项特征，包括粉丝量对数、标题和正文长度、标签数、感叹号数、问号数、Emoji数、情感得分、星期和是否标注发布地；点赞、收藏和评论没有作为输入，以避免目标泄漏。

考虑计算成本，从有效数据中按类别分层抽取60,000条用于比较，再按8:2分层随机划分训练集与测试集。数值缺失以训练集的中位数填补；逻辑回归、线性SVM和MLP同时进行标准化。逻辑回归与SVM使用类别权重平衡，随机森林使用300棵树，梯度提升采用直方图梯度提升分类器，MLP包含64和32个神经元的两个隐藏层并使用早停。表\ref{tab:chapter10-baselines}报告固定测试集结果。鉴于正类仅占约20\%，模型选择以PR-AUC为主，ROC-AUC、F1、精确率和召回率为辅。

梯度提升树的排序能力最佳（PR-AUC=0.440，ROC-AUC=0.736），说明结构化特征与热度之间存在明显的非线性关系；随机森林和MLP次之。逻辑回归与线性SVM的PR-AUC接近，但在类别加权后召回率均约为0.65，更适合“尽量不漏掉潜在爆款”的初筛场景。梯度提升树默认阈值下精确率最高而召回率较低，若用于候选内容筛选，应在验证集上按业务成本降低分类阈值，而不能只依据默认0.5阈值下的F1作结论。

\chapter{针对小红书数据特点的模型改进}

第10章的实证结果表明，仅使用发布前可获得的结构化特征，模型已经能够形成高于随机排序的有效判别能力，但类别不平衡、特征表达有限和决策阈值固定仍然制约实际效果。本章据此给出与现有数据相匹配的改进方案，并明确哪些方法已经在基准实验中落实、哪些方法需要新增数据后才能实施。

\section{类别不平衡与代价敏感学习}
本研究将互动量位于前20\%的笔记定义为高热度样本，因此正负样本比例约为1:4。若仅追求总体准确率，把所有笔记判为普通类即可获得约80\%的准确率，却完全失去识别爆款的能力。因此，实验没有把准确率作为核心指标，而是以PR-AUC衡量少数类的排序质量，并同时报告精确率、召回率与F1。

在模型训练阶段，逻辑回归和线性SVM采用与类别频率成反比的类别权重。该设置使两种线性模型在测试集上的召回率分别达到0.649和0.651，在数值上高于其他模型默认阈值下的召回率，说明代价敏感设置减少了当前测试集中的潜在爆款漏判。不过，召回率的提高伴随着较多假阳性：逻辑回归和线性SVM分别产生3,579和3,611个假阳性样本。因此，这两类模型更适合低成本初筛，而不宜直接用于高成本投放决策。

本研究没有对当前10项结构化特征直接使用SMOTE。其原因是星期、是否标注发布地等变量具有离散语义，简单线性插值可能生成缺乏真实含义的合成样本；同时，过采样若在数据划分前进行，还会造成训练集与测试集之间的信息污染。若后续比较SMOTE、SMOTEENN或EasyEnsemble，应只在每个训练折内部完成重采样，并保持验证集和测试集的原始类别分布。

\section{阈值优化与概率校准}
表\ref{tab:chapter10-baselines}中的精确率、召回率和F1均基于0.5分类阈值，但0.5并不是所有业务场景的最优选择。梯度提升树在该阈值下的精确率达到0.600，召回率却只有0.169，表明模型给出的高分样本较可靠，但大量真实爆款仍位于阈值以下。相反，类别加权的线性模型召回率较高，却需要承担更高的误报成本。

因此，实际应用应先在独立验证集上确定阈值，再锁定阈值并在测试集报告一次最终结果。若目标是为运营人员生成数量有限的候选清单，可选择较高阈值或直接按预测概率取Top-$K$，优先保证精确率；若目标是尽可能覆盖潜在爆款，可降低阈值并为漏判设置更高成本。进一步应用时，还应使用Platt缩放或保序回归检查概率校准，使“预测概率为0.6”具有可解释的实际发生频率，而不仅是排序分数。

\section{特征表达与多模态扩展}
随机森林的重要性结果显示，粉丝量对数的重要性为0.310，居所有特征首位；情感得分、正文长度和标题长度的重要性依次为0.181、0.131和0.108。四项特征合计贡献约73\%的重要性，说明发布者基础影响力和内容表达共同决定了现有模型的主要判别信号。标签数、星期和标点符号等特征提供了补充信息，但单独贡献相对有限。

这一结果也揭示了现有特征工程的边界。长度、符号计数和单一情感得分只能描述文本表层形式，无法识别主题、叙事结构、产品实体与图文一致性。后续可采用中文预训练语言模型编码标题和正文，使用CLIP或视觉主干网络提取封面及配图特征，再将文本、图像和结构化特征分别建模。数据量有限时可采用晚期融合，即对各模态子模型的概率进行加权或堆叠；拥有稳定配对的大规模图文数据后，再比较带跨模态注意力的中期融合。所有模态必须通过同一笔记的稳定标识关联，无法可靠匹配的图片或文本不得强行并入训练样本。

\section{社交传播与时间外验证}
热度不仅由笔记内容决定，还受到发布者历史表现、粉丝构成和平台阶段性流量的影响。若后续能够获得按时间排序的用户历史，可构造近7天、30天和90天的历史互动统计，并确保每条样本只使用其发布时间之前的信息。若能够获得用户---笔记交互边，还可构建二部图并使用GraphSAGE等方法学习传播结构表示，但发布后的点赞、收藏和评论边不能用于发布前预测，否则会形成目标泄漏。

当前基准实验采用分层随机划分，适合在固定样本分布下比较算法。为检查这一划分是否高估模型稳定性，本文进一步使用全部有效日期样本进行一次时间外切分，并使用GroupShuffleSplit进行博主完全隔离的分组切分。梯度提升树在时间外测试上的ROC-AUC和PR-AUC分别为0.739和0.457，在博主分组测试上分别为0.736和0.444；分组测试的训练与测试博主重叠数为0。两组结果与随机切分基准接近，说明当前结构化特征的排序信号并非只来自随机划分或同一博主复用。完整稳健性结果见第18章。

\chapter{模型评估、比较与结论}

\section{评估口径}
分类评估以高热度笔记为正类。精确率表示被模型判为高热度的笔记中真实高热度笔记的比例，召回率表示全部真实高热度笔记中被模型识别出的比例，F1为二者的调和平均。ROC-AUC衡量随机抽取一条正样本和一条负样本时模型将正样本排在前面的概率；PR-AUC则聚焦正类，更能反映类别不平衡场景下精确率与召回率的权衡。

测试集包含12,000条笔记，其中高热度笔记2,401条，正类比例为20.01\%。因此，随机排序的PR-AUC基线约为0.200；五个模型的PR-AUC均在0.405以上，说明它们均提取到了有效预测信号。与此同时，任何单一阈值下的准确率都可能被9,599条负类样本主导，故本研究不以准确率决定最优模型。

\section{综合比较与模型选择}
从阈值无关的排序指标看，梯度提升树的PR-AUC为0.440、ROC-AUC为0.736，均列第一，应作为结构化特征场景下的首选排序模型。相较正类比例0.200的随机基线，其PR-AUC提高约0.240；相较逻辑回归，PR-AUC提高0.035，说明非线性关系与特征交互带来了稳定增益。随机森林和多层感知机的PR-AUC分别为0.424和0.423，二者接近，但随机森林训练更快且更容易解释，可作为性能与可解释性之间的折中方案。

从默认阈值下的分类结果看，梯度提升树以0.600取得最高精确率，适合误报成本较高、候选名额有限的场景；线性SVM以0.651取得最高召回率，适合漏判成本较高的初筛场景；逻辑回归的F1为0.414，在五个模型中最高，且系数方向便于解释，可作为透明度要求较高的基准决策模型。MLP没有超过树模型，说明在当前10项表格型特征上增加网络复杂度并未转化为更好的泛化性能。

\section{稳健性、局限与本部分结论}
本轮比较使用相同的60,000条分层样本、训练测试划分和10项无泄漏特征，模型间横向比较是公平的；数据审计、模型指标、分类报告和特征重要性均可由第10章Notebook复现。当前结论仍有三项限制：补充的时间外验证只有一个边界，尚不能替代多个滚动窗口；模型尚未纳入完整文本、图像和传播网络；F1、精确率和召回率依赖0.5阈值，不能代表调阈后的最佳业务效果。

综合而言，粉丝基础、情感得分和内容长度是现有模型的主要预测信号。梯度提升树排序能力最佳，线性模型覆盖率更高，随机森林则兼顾性能与解释性。本研究由此形成“梯度提升排序、验证集选阈值、场景化输出、时间外复核”的流程。至此，第10章完成模型构建，第11章完成改进设计，第12章完成统一评估与选择，分类模型部分形成闭环。
